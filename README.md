# Data Visualization

Latihan membuat grafik dengan Matplotlib dan Seaborn memakai Tips dataset.

Project page: https://roadmap.sh/projects/data-visualization-tutorial

## Cara Menjalankan
1. Clone repo ini
2. `pip install -r requirements.txt`
3. `python visualize.py`

## Grafik
Histogram, bar chart, box plot, scatter plot, dan heatmap korelasi,
masing-masing dibuat dengan Matplotlib dan Seaborn.
Hasil grafik tersimpan sebagai `mpl_histogram.png` dan `sns_histogram.png`.
